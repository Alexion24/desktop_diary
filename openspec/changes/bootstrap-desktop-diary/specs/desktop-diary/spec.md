## ADDED Requirements

### Requirement: Сохранение данных при запуске из EXE

Сборка Windows MUST сохранять записи и расписание в постоянной базе SQLite. При обычном запуске EXE и запуске из исходников MUST использоваться одна база в профиле пользователя.

#### Scenario: Повторный запуск EXE

- **WHEN** пользователь сохраняет запись и время напоминания, затем повторно запускает EXE
- **THEN** запись и время напоминания доступны после перезапуска

### Requirement: Записи в локальном дневнике

Приложение MUST позволять выбрать дату в календаре и сохранить заполненную форму записи в локальной базе SQLite.
На каждую дату MUST приходиться максимум одна редактируемая запись. Форма содержит текстовые поля «Ощущения», «Методы» и «Заметки». Для сохранения MUST быть заполнено хотя бы одно поле.

#### Scenario: Запись доступна после перезапуска

- **WHEN** пользователь выбирает дату, заполняет форму, сохраняет запись и перезапускает приложение
- **THEN** сохранённая запись доступна при выборе той же даты

### Requirement: Напоминания в фоновом режиме

Приложение MUST позволять задать одно или несколько времён ежедневных напоминаний. Запущенное приложение MUST отправлять уведомления и при скрытом окне.
Уведомление MUST появляться поверх обычных окон и оставаться видимым до закрытия пользователем.

#### Scenario: Два напоминания в день

- **WHEN** пользователь задаёт два разных времени, скрывает окно и приложение продолжает работать в оба момента
- **THEN** приложение отправляет по одному уведомлению в каждое из заданных времён

#### Scenario: Расписание доступно после перезапуска

- **WHEN** пользователь сохраняет расписание и перезапускает приложение
- **THEN** приложение загружает сохранённые времена напоминаний

### Requirement: Настраиваемый автозапуск

Приложение MUST по умолчанию запускаться при входе пользователя в Windows после первоначальной настройки. Приложение MUST позволять выключить и снова включить автозапуск и сохранять этот выбор.

#### Scenario: Автозапуск по умолчанию

- **WHEN** пользователь входит в Windows после первоначальной настройки с включённым автозапуском
- **THEN** приложение запускается в системном трее со скрытым окном

#### Scenario: Отключение автозапуска

- **WHEN** пользователь выключает автозапуск и снова входит в Windows
- **THEN** приложение не запускается автоматически

#### Scenario: Повторное включение автозапуска

- **WHEN** пользователь снова включает автозапуск и входит в Windows
- **THEN** приложение запускается в системном трее со скрытым окном

### Requirement: Печатный месячный отчёт

Приложение MUST сохранять записи месяца, открытого в календаре, в виде HTML-таблицы для печати из браузера.

#### Scenario: Экспорт выбранного месяца

- **WHEN** пользователь выбирает месяц и экспортирует отчёт при наличии записей за этот и соседний месяцы
- **THEN** сохранённый файл содержит таблицу с заголовками колонок и всеми записями выбранного месяца, упорядоченными по дате
- **AND** записи соседних месяцев отсутствуют в отчёте
