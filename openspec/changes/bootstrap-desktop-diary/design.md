## Предлагаемая архитектура

- Первая целевая платформа — Windows. Один процесс приложения обслуживает окно, значок в системном трее и таймер напоминаний.
- Записи хранятся в SQLite, по одной на дату. Поля «Ощущения», «Методы» и «Заметки» заполняются текстом. Время ежедневных напоминаний задаётся по местному времени компьютера и сохраняется между запусками.
- Для отчёта берём записи с первого по последний день открытого в календаре месяца, сортируем по дате и сохраняем HTML-таблицу для печати из браузера.
- Для первой версии достаточно модулей интерфейса, хранения, напоминаний и отчёта. Проверим трей и уведомления на Windows до реализации основной формы.
- Настройка автозапуска при входе в Windows включена по умолчанию. Пользователь может выключить её и снова включить. Приложение при автозапуске начинает работу в трее со скрытым окном.

## Интерфейс

Выбран **PySide6 / Qt Widgets**. Qt предоставляет календарь и системный трей.

## Сборка Windows

Ruff и PyInstaller установлены как зависимости разработки. PyInstaller собирает один файл DesktopDiary.exe. Обычный запуск из исходников и из EXE использует один путь к SQLite в профиле Windows. Для проверки можно указать отдельный каталог через `--data-dir`.

## Решения перед реализацией

- Подтвердить, достаточно ли Windows для первой версии.
- Подтвердить предлагаемое поведение напоминаний. Закрытие окна скрывает его в трей, команда «Выход» завершает процесс и останавливает напоминания. Предлагается пропускать уведомления, время которых прошло во время сна или остановки приложения.
