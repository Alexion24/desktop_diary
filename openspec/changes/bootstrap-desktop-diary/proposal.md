## Why

Нужен локальный дневник-календарь для регулярных записей об ощущениях и применённых методах. Напоминания помогают вовремя заполнять дневник, а месячная таблица нужна для печати.

## What Changes

- Подготовить десктопный проект на Python с управлением окружением через uv и локальным хранением в SQLite.
- Добавить календарь и форму записи. Дата, ощущения, заметки и методы обозначают назначение формы. Состав, типы и обязательность полей согласуем отдельно.
- Поддержать работу со скрытым окном и настройку одного или нескольких ежедневных напоминаний.
- Добавить переключатель автозапуска при входе в Windows. По умолчанию автозапуск включён.
- Добавить экспорт записей выбранного месяца в HTML-таблицу для печати из браузера.
- Добавить проверки Ruff и воспроизводимую сборку EXE для Windows.

## Capabilities

### New Capabilities

- `desktop-diary`: календарь, локальные записи, фоновые напоминания и месячный отчёт.

## Impact

Новый локальный проект. Первая версия рассчитана на один сценарий использования. Несколько видов дневника и настройка колонок — возможное следующее изменение OpenSpec.
