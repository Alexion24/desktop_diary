# Дневник

Локальный дневник для Windows на Python и PySide6. На вкладке «Дневник» выберите дату в календаре и откройте запись. На каждую дату сохраняется одна редактируемая запись с полями «Ощущения», «Методы» и «Заметки».

## Запуск

В корне проекта выполните команду. uv подготовит окружение на Python 3.11 и установит зависимости из файла блокировки.

```powershell
uv run --locked main.py
```

Кнопка закрытия окна скрывает дневник в системном трее. В меню значка можно снова открыть окно, проверить напоминание или завершить приложение через «Выход». Напоминание появляется поверх остальных окон и остаётся до закрытия.

На вкладке «Напоминания» можно добавить несколько ежедневных напоминаний или удалить выбранное время. Расписание сохраняется автоматически. Напоминания срабатывают по местному времени компьютера, пока дневник запущен, в том числе когда его окно скрыто в трее.

При первом запуске дневник добавляется в автозапуск текущего пользователя Windows. При входе в систему он открывается сразу в трее. Изменить это можно флажком «Запускать дневник при входе в Windows».

Для печати откройте нужный месяц на вкладке «Дневник» и нажмите «Сохранить таблицу за открытый месяц». Откройте сохранённый HTML-файл в браузере и нажмите Ctrl+P.

## Проверка и сборка EXE

Из корня проекта на Windows выполните команды.

```powershell
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked pyinstaller --noconfirm DesktopDiary.spec
```

Готовый файл находится в `dist\DesktopDiary.exe`. Запуск через Python и через EXE использует одну базу `%LOCALAPPDATA%\DesktopDiary\diary.sqlite3`. Если автозапуск включён, при ручном запуске EXE дневник регистрирует путь к этому EXE.

Для проверки на отдельной базе запустите `.\dist\DesktopDiary.exe --data-dir .\build\smoke-data`. В этом режиме используется указанная папка и настройка автозапуска недоступна. Создайте запись и добавьте время напоминания, завершите приложение через «Выход» в трее, повторите команду и проверьте оба значения.

План разработки находится в [OpenSpec](openspec/changes/bootstrap-desktop-diary/tasks.md).
